Top 200 medications

Flashcards for the top 200 drugs: generic and brand names, drug class, indication, schedule, and what to watch out for.

Cards are grouped by pharmacological class, in the same order as my class slides; switch Group by to Condition treated to study by indication instead. Pick a study mode, narrow the deck to one class, and click the card (or press Space) to flip it. Mark each card Got it or Still learning. Your progress is saved in this browser, and Only still learning drills just the cards you have not mastered yet.

Keyboard: Space flip · ← → previous / next · K got it · L still learning

fc = import(new URL("../../flashcards.js", document.baseURI).href)
flashcards = fc.flashcards
esc = fc.esc
meds = FileAttachment("top200medications.csv").csv()
legend = FileAttachment("Legend.csv").csv()
flashcards({
  cards: meds,
  storageKey: "pharmtech-top200-known",
  idField: "generic",
  groupings: [
    { label: "Drug class", field: "pharm_class", orderField: "class_order" },
    { label: "Condition treated", field: "group", orderField: "condition_order" }
  ],
  searchFields: ["generic", "brand", "pharm_class", "drug_class", "indication", "notes"],
  placeholder: "Drug, brand, class, or interaction",
  invalidation,
  modes: {
    generic: {
      label: "Generic → Brand, class, use",
      front: d => `<div class="fc-kicker">Generic</div><div class="fc-big">${esc(d.generic)}</div>`,
      back: d => details(d, "brand")
    },
    brand: {
      label: "Brand → Generic",
      front: d => `<div class="fc-kicker">Brand</div><div class="fc-big">${esc(d.brand)}</div>`,
      back: d => details(d, "generic")
    },
    class: {
      label: "Generic → Class & indication",
      front: d => `<div class="fc-kicker">What class is it, and what is it for?</div><div class="fc-big">${esc(d.generic)}</div>`,
      back: d => `<div class="fc-big fc-mid">${esc(d.drug_class)}</div><div class="fc-row">${esc(d.indication)}</div>`
    },
    watch: {
      label: "Generic → Watch out for (interactions, storage)",
      front: d => `<div class="fc-kicker">What should you watch out for?</div><div class="fc-big">${esc(d.generic)}</div><div class="fc-row">${esc(d.brand)}</div>`,
      back: d => d.notes
        ? `<div class="fc-kicker">Watch out</div><div class="fc-row fc-answer">${esc(d.notes)}</div>`
        : `<div class="fc-row">No special interaction or storage notes. Know the class and use: <strong>${esc(d.drug_class)}</strong>, ${esc(d.indication)}.</div>`
    }
  }
})
statusClass = s => s.startsWith("C-") ? "fc-ctrl" : s.startsWith("OTC") ? "fc-otc" : "fc-rx"
details = (d, lead) => `
  <div class="fc-kicker">${lead === "brand" ? "Brand" : "Generic"}</div>
  <div class="fc-big fc-mid">${esc(lead === "brand" ? d.brand : d.generic)}</div>
  <dl class="fc-dl">
    <dt>Class</dt><dd>${esc(d.drug_class)}</dd>
    <dt>Used for</dt><dd>${esc(d.indication)}</dd>
    <dt>Status</dt><dd><span class="fc-badge ${statusClass(d.status)}">${esc(d.status)}</span></dd>
    ${d.notes ? `<dt>Watch out</dt><dd class="fc-note">${esc(d.notes)}</dd>` : ""}
  </dl>`

For laws, sig codes, storage, and calculations, see the PTCB review deck.
